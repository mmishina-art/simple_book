    まだ本がありません。パソコンで PDF から作った本ファイル(.md)を、下のボタンから取り込んでください。

    PDF から本ファイルを作るには
    1. パソコンに poppler と tesseract(日本語データつき)を入れる
    2. node scripts/pdf2book.ts 本.pdf を実行すると、OCR で 本.md ができる
    3. できたファイルを、AirDrop・メール・クラウドなどでスマホに送り、「本を追加」で選ぶ

    くわしくは README を見てください。

    しおり・設定のバックアップ

    しおりと読書の設定は、このブラウザの中にだけ保存されています。ファイルに残しておくと、消えたときに戻せます。本そのものは含まれないので、本ファイルは別に取っておいてください。

      ホーム画面に追加して使う

      インストールすると、ホーム画面から開けて、オフラインでも使えます。

      iPhone / iPad
      1. Safari でこのページを開く
      2. 共有ボタン(□から↑が出ているマーク)をタップ
      3. 「ホーム画面に追加」を選ぶ
      4. 右上の「追加」をタップ
      Android
      1. Chrome でこのページを開く
      2. 右上のメニュー(⋮)をタップ
      3. 「アプリをインストール」または「ホーム画面に追加」を選ぶ
      4. 「インストール」をタップ
      パソコン(Chrome / Edge)
      1. アドレスバーの右端にあるインストールのマークをクリック
      2. 「インストール」を選ぶ
      新しいバージョンがあります
